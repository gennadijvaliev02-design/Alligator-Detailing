# Alligator Detailing — демо сайта

Адаптивная демонстрационная версия сайта детейлинга в Рассудово.

## Возможности

- Сравнение фотографий до/после: Toyota Camry и Kia Ceed.
- Галерея реальных работ студии.
- Раскрывающийся прайс.
- Форма, которая подготавливает обращение в Telegram.
- Мобильная версия, SVG-иконки, анимации с поддержкой reduced motion.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не требуются.

Для GitHub Pages выберите публикацию из корня ветки `main`. Папку `assets` необходимо сохранить: в ней фотографии сайта.

Фотографии предоставлены для демонстрации проекта. Цены перенесены из опубликованного прайса студии и требуют подтверждения перед реальным запуском.
